- [2026-10-12] Ink 7 parses one stdin read into several key events: each run of text, each escape sequence (arrows) and each DEL/BS byte (`splitBackspaceBytes`). In tests, put several keys in ONE `press`/`stdin.push` to model a coalesced read; in the mocked suite, call several keys on one `capturedInputHandler` without re-rendering.
