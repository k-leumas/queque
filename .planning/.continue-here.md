## Queued Quick Task (not yet executed)

The user wants to fix how Enter selection works:

**Current behavior**: Enter selects a candidate and writes just the command to the shell buffer.

**Desired behavior**:
1. The selected command is written to LBUFFER (left buffer)
2. The explanation is appended as a shell comment: `command  # explanation`
3. If the command contains placeholder inputs (e.g. `<filename>`, `[path]`), the cursor is placed at the first placeholder

**Files to look at**:
- `src/ui/CandidateSelect.tsx` — `onSelect(command)` callback, currently only passes command string
- `src/client/run-foreground.ts` — `onSelect` handler that calls `writeShellResult`
- `src/contracts/candidates.ts` — `CommandCandidate` has both `command` and `explanation` fields
- `src/client/result-writer.ts` — writes the FIFO result `{kind: "replace-buffer", lbuffer, rbuffer}`

**Key insight**: `onSelect` in `CandidateSelect.tsx` currently only passes `command`. It needs to pass both `command` and `explanation`. The `run-foreground.ts` handler then builds: `lbuffer = command + "  # " + explanation` and sets `rbuffer = ""` with cursor at end (or before first placeholder).
