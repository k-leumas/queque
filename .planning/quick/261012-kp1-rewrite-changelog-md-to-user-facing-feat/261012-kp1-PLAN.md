<objective>
Make CHANGELOG.md scannable: user-facing Features / Bug Fixes / Deprecations (outcome copy) with the commit laundry list hidden in `<details>`. Future releases keep that shape by replacing `@semantic-release/release-notes-generator` with an in-repo plugin that asks an LLM to summarize the changeset since the last tag.

Locked decisions:
- High-level bullets describe how the product got better, not tickets or internals.
- Detailed conventional-commit lists live under `<details><summary>Detailed changes</summary>`.
- Deprecations only when there is breaking/removed user-facing behavior.
- Unreleased (v0.5.0..HEAD, phase 09.1) is documented now; the plugin strips `## [Unreleased]` at the next release so notes are not duplicated.
- `ANTHROPIC_API_KEY` missing or an LLM failure must not fail the release: details-only notes still publish.
</objective>
