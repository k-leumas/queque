# Phase quick-261011-e43 Plan 01: Zellij header clip fix Summary

The Zellij floating pane now reserves one PTY row for Ink's trailing cursor line (`INK_TRAILING_CURSOR_ROWS = 1` beside `ZELLIJ_FLOATING_FRAME_LINES`). An N-line modal below the cap gets an N + 3 pane: N content rows, 2 rows of frame, and 1 cursor row. The `queque ›` header no longer scrolls into pane scrollback (`SCROLL: 0/1`).

**Status: complete.** Task 1 (tracer, TDD) is committed and verified. Task 2 (live Zellij human check) was **approved by the user on 2026-10-11**: "this works". Automated live-Zellij evidence (below) already shows the fix working in a real pane.
