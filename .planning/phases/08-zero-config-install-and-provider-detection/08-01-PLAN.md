In `src/providers/detect.ts`:

1. Add `claudeAuthPresent()`:

```typescript
async function claudeAuthPresent(): Promise<boolean> {
  if (process.env.CLAUDE_CODE_OAUTH_TOKEN || process.env.ANTHROPIC_AUTH_TOKEN) {
    return true;
  }
  if (process.platform === 'darwin') {
    return true; // Keychain auth; validated by subprocess adapter at call time
  }
  return claudeAuthFileExists();
}
```

2. Change Step 2 call site from `claudeAuthFileExists()` to `claudeAuthPresent()`.
   Keep `claudeOnPath()` as the outer gate: `if (claudeOnPath() && (await claudeAuthPresent()))`.
