<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keyboard (/dev/tty) → picker | untrusted free-text answers choose what is persisted |
| picker → filesystem | writes ~/.config/qq/provider.json, a file other qq processes trust |
| picker → other processes | restarts the qq daemon and may spawn a URL opener |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-18 | Information Disclosure | provider.json contents and mode | high | mitigate | Pins are schema-validated (strict, no secret fields) before writing; file mode 0600 in a 0700 dir; test asserts mode and that no key value reaches output. |
| T-08-19 | Tampering | temp file during atomic write | medium | mitigate | Temp file created with flag wx (exclusive, does not follow a pre-planted symlink) in the target directory, then renamed; temp unlinked on error. |
| T-08-20 | Elevation of Privilege | restartDaemon process signalling | medium | mitigate | assertSafeSocketPath gate; only lsof listeners of the qq socket are signalled and never the current pid (existing replaceStaleListener); test rejects /etc/qq.sock. |
| T-08-21 | Tampering | `qq init zsh` output piped into ~/.zshrc | medium | mitigate | dispatchInit routes only the literal provider; init.ts untouched; picker writes to /dev/tty only (test asserts nothing on process.stdout). |
| T-08-22 | Spoofing | URL opener / command execution | medium | mitigate | openUrl runs only after an explicit y, only with the OLLAMA_DOWNLOAD_URL constant, via spawn without a shell. |
| T-08-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs; readline/promises, tty, and fetch are Node built-ins. |

ASVS L1 (block on high): T-08-18 mitigated with automated tests.
</threat_model>
