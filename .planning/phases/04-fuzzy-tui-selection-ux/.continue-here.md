## What Needs to Be Implemented (to go GREEN)

### Step 1 — `CandidateSelect.tsx`: update `onSelect` call + Props interface

Change `onSelect: (command: string) => void` to `onSelect: (command: string, explanation: string) => void`.

In the return handler (currently line ~87):
```typescript
// Before
onSelect(visible[selectedIndex]?.command ?? visible[0]!.command);

// After
const selected = visible[selectedIndex] ?? visible[0]!;
const explanation = selected.explanation || `see man ${selected.command.split(' ')[0]}`;
onSelect(selected.command, explanation);
```

### Step 2 — `run-foreground.ts`: build lbuffer with explanation as shell comment

Change `onSelect` callback (around line 147) to:
```typescript
onSelect: async (command: string, explanation: string) => {
  if (resolved) return;
  resolved = true;
  await writeShellResult(resultFile, {
    kind: 'replace-buffer',
    lbuffer: `${command}  # ${explanation}`,
    rbuffer: request.rbuffer,
    query: request.lbuffer,
  });
  unmount?.();
},
```

### Step 3 — `shell/zsh/qq.zsh`: print context line in `_qq_apply_result`

When `query` field present in result JSON, print dimmed context line:
```zsh
local query
query=$(jq -r '.query // empty' <<< "$result_json")
if [[ -n "$query" ]]; then
  print -P "%F{240}que-que query: ${query}%f"
fi
```

Check `src/contracts/shell.ts` — may need optional `query` and `explanation` fields in the replace-buffer result variant.
