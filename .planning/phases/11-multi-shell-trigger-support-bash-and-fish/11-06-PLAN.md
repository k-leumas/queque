<objective>
bash feels as instant as zsh: the moment `??` fires, bash paints the `queque › <query>` / `thinking…` skeleton before Node starts, and a shared TypeScript reference plus a cross-shell byte-parity test keep the zsh and bash painters from drifting (D-04).

Purpose: D-04 says pull the zsh modal skeleton into a shared spec that every adapter paints, without two diverging hand copies. A generated byte file cannot work (the frame depends on the lbuffer and the column count), a shared sh helper costs a fork and fish cannot source it, and painting from the client defeats the purpose. Chosen (Claude's discretion): a TS oracle + native fork-free painters per adapter + a parity test that runs every adapter against the oracle (RESEARCH Pattern 3). Phase 12 adds a fish row to `ADAPTERS`.
Output: `src/shared/instant-frame-spec.ts`, UI constants read from it, `tests/instant-frame-parity.test.ts` (zsh + bash), bash frame functions and their placement in `_qq_question`, bash-widget b8-b9.

Expected duration: 35-50 min. Runs in parallel with plans 02, 03 and 04. Leaves `shell/zsh/queque.zsh` unchanged (plan 02 owns it this wave).
</objective>
