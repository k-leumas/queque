### Gaps Summary

One gap is left, and it comes from the same root cause as CR-01: the result depends on how stdin chunks the keys. Ink 7 keeps `\r` and `\t` inside a text run, so `ls⏎` or `log⏎` typed in one read (for example during Node startup, or while `thinking…` shows) becomes invisible filter text. The list then shows `no matches` and Enter does nothing until Backspace. The 09.1-10 plan knew this: its invariance table puts an arrow or DEL before every CR and Tab. Yet its code comment and ROADMAP line claim full invariance. The defect predates the phase, but it sits on the D-07 (early Enter) and D-09 (filter typed during thinking) paths that this phase promises and encourages. No later milestone phase covers it (Phase 999.1 is unrelated backlog). The fix is small, in `src/ui/CandidateSelect.tsx` plus three invariance rows (see `gaps.missing`). Run `/gsd-plan-phase 09.1 --gaps` or a quick fix, then the UAT 5 live re-test.
