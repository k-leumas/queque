<objective>
Close UAT gap G-09.1-5 (major, UAT test 5). In the user's words: "the filter value should be empty upon opening of the modal as the query text is displayed above this". Text typed during `thinking…` is currently appended to the lbuffer: `show me how to use z3` becomes `show me how to use z3 smt`, and the finished list shows `no matches`.

Root cause (binding, from .planning/debug/modal-filter-prefilled-with-query.md). `CandidateSelect` seeds its FILTER query state with `initialQuery`, which is the lbuffer, under phase 03.1 decision D-01. Printable keys append to that state. The 09.1 WR-04 guard (commit 17bf7d3) only lets the zero-match clear run while the query still equals `initialQuery`, so once the user types, the lbuffer plus the typed text is never cleared. The phase 04 `queque ›` header already shows the lbuffer, so the seed is redundant.

The fix: seed the query state with an empty string. Then remove the two zero-match clears in the arrival block. They existed only to undo the seed, and with an empty seed they could only throw away text the user typed. The first-arrival selection and Tab reset stays, and so do the later-arrival keep-highlight logic and the WR-06 clamp. Tests that encoded the pre-fill are rewritten to the new contract, never deleted. 03.1 D-01/D-02 are marked superseded in the planning docs and in cerebrum.

Choices made at Claude's discretion:
- The prop keeps its name `initialQuery`. It gets a JSDoc saying it is the header text and estimator input only. The gap's `missing` list says to keep it for the header and line estimator. A rename would touch run-foreground.ts, `CandidateSelectLayoutInput` in modal-layout.ts and about 30 test call sites, with no change in behaviour.
- `src/client/run-foreground.ts` and `shell/zsh/queque.zsh` are not changed. run-foreground passes the constant `request.lbuffer`, and the widget's instant frame already leaves the FILTER row blank (debug session, Eliminated).

Purpose: the modal reads as "your question above, an empty filter below". Typing narrows the list by exactly what was typed, before and after rows arrive (D-09).
Output: a one-line seed change and the removed clears in `src/ui/CandidateSelect.tsx`, a real-Ink regression describe, the rewritten pre-fill tests, superseded markers in the planning docs, and OpenWolf/buglog/debug-session records.
</objective>
