---

## Sampling Rate

- **After every task commit:** Run the task's `pnpm exec vitest run tests/<file>.test.ts` + `pnpm typecheck`
- **After every plan wave:** Run `pnpm test:run && pnpm typecheck && pnpm lint`
- **Before `/gsd-verify-work`:**
  - The full suite must be green.
  - Then do one real-provider latency and cancel run on an idle machine; check `uptime` first.
- **Max feedback latency:** 60 seconds
