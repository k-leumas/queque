> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 4.0.4 |
| **Config file** | `vitest.config.*` at repo root (existing) |
| **Quick run command** | `pnpm exec vitest run tests/<file>.test.ts` (never `pnpm test:run -- <file>`) |
| **Full suite command** | `pnpm test:run && pnpm typecheck && pnpm lint` |
| **Estimated runtime** | ~60 seconds (full suite; timing guards flake under heavy load, bug-206) |

---

## Sampling Rate

- **After every task commit:** Run the task's `pnpm exec vitest run tests/<file>.test.ts` + `pnpm typecheck`
- **After every plan wave:** Run `pnpm test:run && pnpm typecheck && pnpm lint`
- **Before `/gsd-verify-work`:**
  - The full suite must be green.
  - Then do one real-provider latency and cancel run on an idle machine; check `uptime` first.
- **Max feedback latency:** 60 seconds
