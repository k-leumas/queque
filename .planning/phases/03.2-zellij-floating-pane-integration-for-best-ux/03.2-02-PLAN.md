## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FIFO path → result-writer.ts | resultFile argument is caller-supplied; an attacker controlling the path could redirect writes |
| process.env → run-foreground.ts | ZELLIJ env var drives branching; an attacker able to set env vars could force or suppress the Zellij path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.2-01 | Information Disclosure | FIFO world-readable — another process reads result before widget | mitigate | FIFO path generated by widget via mktemp -u /tmp/qq-fifo.XXXXXX; unique per invocation; /tmp default permissions prevent other-user reads on macOS (sticky bit); world-readable risk is low in single-user terminal context — accept residual risk per RESEARCH.md §Security Domain |
| T-3.2-02 | Tampering | FIFO path injection via LBUFFER content reaching --result-file argument | mitigate | Widget passes fifo_path as a quoted shell variable ("$fifo_path"); widget itself generates the path via mktemp; client receives it via --result-file CLI arg which is parsed by cac and passed to writeShellResult as a string — no shell evaluation of this path in Node.js |
| T-3.2-03 | Denial of Service | Orphaned FIFO left on disk if Node.js client crashes before writing | mitigate | Widget sets EXIT ERR INT trap to rm -f the FIFO; result-writer.ts FIFO branch is a single await fsp.writeFile — crash window is minimal; FIFO is cleaned up by widget trap regardless |
| T-3.2-04 | Tampering | zellij run path injection via malformed ZELLIJ env var content | accept | ZELLIJ env var is only read as a boolean presence check (process.env['ZELLIJ'] !== undefined); its value is never interpolated into shell commands or SQL — no injection surface |
</threat_model>
