<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keyboard → useInput | Printable characters enter query state; never written to disk or sent to provider |
| provider response → CandidateList → modal render | fetchCandidates output flows through Zod-validated CandidateList before reaching the UI |
| modal onSelect → writeShellResult → resultFile | Selected command written to result file; shell reads it via _qq_apply_result |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-033-01 | Spoofing | useInput printable char handler | accept | Query state is local to the component; no authentication surface involved |
| T-033-02 | Tampering | filterCandidates query input | accept | Filter runs client-side over already-validated CandidateList; query string modifies display only, not the list stored in state |
| T-033-03 | Repudiation | writeShellResult command write | accept | No audit logging required for v1; the user manually confirms by pressing Enter |
| T-033-04 | Information Disclosure | query string in SearchInput | accept | Query is typed by the user; displayed back to them in the same TTY session |
| T-033-05 | Denial of Service | rerender() called after unmount (Pitfall 4) | mitigate | fetchCandidates .then/.catch callbacks reference `app.rerender` — after `unmount()` is called, React ignores state updates on unmounted components; no crash results; Ink's unmount is safe to call before rerender silently no-ops |
| T-033-06 | Elevation of Privilege | command string from CandidateList written to shell buffer | accept | Command is written to buffer only (SAFE-01); never auto-executed; user presses Enter in zsh to run it |
</threat_model>
